EXISTING APPLICATION
The main file is stock_rag_chatbot.py. The project includes .env, .env.example, README.md, requirements.txt, and an existing ChromaDB database.

The current RAG pipeline:
- Reads PDF and PPTX documents.
- Extracts document text.
- Uses RecursiveCharacterTextSplitter with chunk_size=1000 and chunk_overlap=150.
- Uses sentence-transformers/all-mpnet-base-v2 embeddings with a 768-dimensional vector configuration and normalized embeddings.
- Stores chunks in the persistent ChromaDB collection investor_presentations using cosine similarity.
- Uses Streamlit for the chat interface.
- Embeds user questions, retrieves Top K relevant chunks (currently K=4), and passes retrieved context to OpenAI GPT-4o-mini.
- Uses metadata including company, ticker, fiscal_year, quarter, document_type, source_path, and file_hash where implemented.
